Embed customizable itch.io game cards directly inside Gutenberg editor with theme options and side-padding controls.

###

**Itch.io Embed** is the ultimate Gutenberg block for indie game developers, bloggers, and gaming journalists who want to showcase itch.io game cards seamlessly on WordPress.
Paste your game URL, and the plugin automatically fetches game data via REST API to build a clean, interactive iframe widget.

### Key Features
* **Auto Data Fetching:** Just paste the itch.io URL and click generate.
* **Custom Color Palette:** Adjust background, text, link, and border colors to match your theme.
* **Dark Theme Toggle:** Instantly switch between light and dark embed styles.
* **Independent Side Padding:** Fine-tune top, right, bottom, and left margins separately.
* **Gutenberg Native:** Features an official itch.io branded icon in the block inserter.
* **Lightweight & Fast:** Zero heavy external libraries loaded on the frontend.

### Automatic Installation
1. Log in to your WordPress admin dashboard.
2. Go to **Plugins > Add New**.
3. Search for `Itch.io Embed`.
4. Click **Install Now**, then **Activate**.

### Manual Installation
1. Download the plugin ZIP file.
2. Upload the `itchio-embed` directory to your `/wp-content/plugins/` directory.
3. Activate the plugin through the **Plugins** menu in WordPress.

### Frequently Asked Questions ==
* Do I need an itch.io API Key? No API key or developer registration is required! The plugin fetches the required metadata using public endpoints.
* Can I customize the appearance of the embed card? Yes! You can change background color, text color, link color, border width/color, dark mode, and set individual side paddings.
* Is this block mobile responsive? Yes, the iframe wrapper automatically scales down to fit smaller screens.
